# Floor versions (>=) throughout rather than exact pins. Exact-pinning
# packages that other entries in this file also depend on (transitively)
# is what caused three separate ResolutionImpossible errors in a row here -
# langchain-core vs langchain-community, mcp vs fastmcp, python-dotenv vs
# uvicorn[standard]/fastmcp. Floors let pip's resolver pick a mutually
# compatible set itself instead of guessing exact versions with no resolver
# to check them against.
